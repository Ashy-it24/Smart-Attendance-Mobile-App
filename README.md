# Smart Attendance Management System

A Flutter-based mobile application for attendance management using Face Recognition and Geofencing.

## Features

- 🔐 Firebase Authentication
- 📸 Face Recognition using TensorFlow Lite
- 📍 Geofencing for location-based attendance
- 📊 Admin Dashboard with Analytics
- 📱 Material 3 Design
- 🏗️ Clean Architecture (MVVM)

## Tech Stack

- **Frontend:** Flutter, Dart
- **Backend:** Firebase (Auth, Firestore, Storage)
- **ML:** TensorFlow Lite, MobileFaceNet
- **Location:** Geolocator
- **State Management:** Provider

## Project Structure

```
lib/
├── core/              # Core utilities, constants, and helpers
├── data/              # Data layer (models, repositories, datasources)
├── domain/            # Business logic (entities, use cases)
├── presentation/      # UI layer (screens, widgets, providers)
├── routes/            # Navigation and routing
└── main.dart          # Entry point
```
